# KretivOS Product Scope

## Product principle

KretivOS is organised around company and client workspaces rather than executive roles. Every important record can be created, linked, approved, searched, automated and analysed.

## End-to-end flows

### Client acquisition
Lead → Qualification → Proposal → Quotation → Approval → Acceptance → Onboarding

### Customer onboarding
Client details → Service blueprint → Generated documents → Workspace provisioning → Project kickoff

### Sales and payment
Quotation → Sales order → Invoice → Payment → Receipt

### Procurement
Purchase request → Supplier comparison → Approval → Purchase order → Goods receipt → Supplier invoice → Payment

### Project delivery
Scope → Milestones → Tasks → Creative/technical production → QA → Client approval → Deployment → Warranty

### Marketing production
Marketing plan → Persona/journey → TOFU/MOFU/BOFU → Content calendar → Storyboard → Prompt/assets → Approval → Publishing → Analytics

### Chef Ammar settlement
Channel sales close → Weekly statement → Joint verification → Management-fee invoice + ad reimbursement → Tuesday payment → Receipt

### Monthly incentive
Verified monthly volume → Applicable scenario/tier → Team/company split → Invoice/payment advice → Payment by configured due date

## Shared capabilities

- Universal search and command palette
- Comments, mentions and attachments
- Status, owner and due date
- Approval history and document versions
- Activity/audit feed
- Tags and saved views
- AI actions embedded in each workspace
- Notifications
- Reusable service blueprints
- Reusable document templates
- Automation triggers and actions
- Offline-friendly PWA shell
